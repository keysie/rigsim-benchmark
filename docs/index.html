Repository The stick data.json

Every run of the rigsim measurement stick: a machine booted from the stick, measured its CPU, memory, GPUs, llama.cpp and Blender unattended, and powered off. Select a run for the exact versions of every tool behind it; “files” opens its raw data.
Loading runs…

What the data promises: everything that can influence a result is recorded — the exact version of every tool and component, and every decision the stick made while being built or measuring (fallbacks, skipped steps, overrides, the exact command lines). Runs are never changed after publication and there is no list of known errors: judging whether a result is affected by a bug in some version is up to whoever uses the data, from what each run records.

Data: CC BY 4.0, code: Apache 2.0. Machines are identified by a salted hash, never by serial numbers.
